Leaf bench test: start to finish

Everything you need to measure healthy and stressed leaves with the sensor, log every reading to a file, and come back with data for Slide 3. Steps 1 to 3 are done the night before; 4 to 10 on campus.

The night before

1

Pack the kit

5 min

The spacer is the most important item: it holds the sensor at the same height for the paper and every leaf. 3 to 5 cm is ideal.

2

Install pyserial (once)

2 min · Terminal

The logger needs one Python library to talk to the Uno. Open Terminal (Cmd + Space, type "Terminal") and run:

python3 -m pip install pyserial
If you see an externally-managed-environment error, run this instead. It makes a small private Python setup: 
python3 -m venv ~/ndvi-env && source ~/ndvi-env/bin/activate && pip install pyserial
With this route, run source ~/ndvi-env/bin/activate each time you open a new Terminal window.
3

Upload the final sketch and do a dry run

10 min · Arduino IDE, then Terminal
  1. Open sketch_oct16a_rgb.ino in the Arduino IDE. Check Tools → Board → Arduino Uno and Tools → Port.
  2. Click Upload. The LED should flash green, then red.
  3. Close the Serial Monitor (if it's open), then start the logger as in step 6 and do a mini test: w on paper, two r on any leaf, then q.
Done when: the logger prints saved sample ... NDVI=... and a file called ndvi_log.csv appears in the Arduino folder. Delete that file afterwards so tomorrow starts clean.

On campus: setup

4

Pick the spot and the leaves

5 min
  • Outdoors, steady daylight. All sun or all cloud; avoid moments when clouds keep passing. Note the time and weather.
  • Measure leaves on the plant, not picked: picked leaves change within minutes, and it's kinder to campus plants.
  • Find 5 healthy green and 5 yellow or brown leaves, ideally on the same plant species so the comparison is fair.
      sunlight ↘
   [ sensor ]  ← face down, on the spacer
       ↕  3–5 cm
   ~~~ leaf ~~~  ← flat, not shaded by you or the board
5

Power up and check the light level

5 min · Serial Monitor
  1. Plug the Uno into the laptop. LED flashes green then red.
  2. Open the Serial Monitor (115200 baud) and type s to pause the stream.
  3. Put the white paper under the sensor at the spacer height and type w. Look at the raw counts on the WHITE REFERENCE STORED line.
White paper countsWhat to do
About 5,000 to 50,000Good. Carry on.
"Sensor saturated" warningToo bright. Lower the gain one step to AS7343_GAIN_32X and re-upload, or measure in light shade.
Under about 2,000Too dark. Raise the gain to AS7343_GAIN_128X and re-upload.
  1. Put one healthy leaf under the sensor and type r. The LED should turn green.
  2. Close the Serial Monitor. The logger can't connect while it's open.
6

Start the logger

2 min · Terminal

Go to the Arduino folder:

cd ~/Documents/"Cowork OS"/Masters/Modules/"Cleantech Project"/"Part 1"/Arduino

Then start it:

python3 ndvi_logger.py
You should see: Connected to /dev/cu.usbmodem… Saving to …/ndvi_log.csv then a > prompt. The board restarts when the logger connects (LED flashes green, red), which is normal.
If it says No Arduino port found: copy the port name from the IDE (Tools → Port) and add it, e.g. python3 ndvi_logger.py /dev/cu.usbmodem1101

The tests

How the logger works: label … sets a name that's saved with every reading until you change it. w saves a white reference, r saves one reading. After each r you'll see saved sample [label] NDVI=…. Watch the LED too: it should match.
7

Test A: healthy vs stressed

20 min · the main result for Slide 3
  1. Paper under the sensor, then label white and w.
  2. For each healthy leaf: set the label, then take 3 readings.
  3. Same for the stressed leaves.
  4. Retake w every 10 minutes, or whenever the light changes.
  5. Photograph each leaf with the sensor above it.

Expect: healthy leaves mostly GREEN with higher NDVI; stressed leaves RED with lower NDVI. Don't worry if a few don't match: that's data too. Write down anything odd (shade, wet leaf, wind).
8

Test B: repeatability

10 min · how consistent the readings are
  1. Pick one healthy leaf.
  2. Take 10 readings. Between each one, lift the sensor away and put it back.
label repeat
r
(lift sensor away, put it back)
r
… 10 readings in total …
Gives you: a figure like "NDVI 0.42 ± 0.03", which tells the receiving team how much to trust a single reading.
9

Test C: light conditions Optional

10 min · evidence for the white-card limitation
  1. Same leaf in the sun: label white sun, w, then label sun and 3× r.
  2. Move the leaf (or yourself) into shade without retaking w: label shade old-ref, 3× r.
  3. Now retake the reference in the shade: label white shade, w, then label shade new-ref, 3× r.
Shows: how far NDVI drifts when the light changes and you don't recalibrate, and whether retaking w fixes it.

Finish

10

Save and send the data

2 min
  1. Type q and press Enter. The logger prints Saved to …/ndvi_log.csv.
  2. The file is in the Arduino folder: Cowork OS › Masters › Modules › Cleantech Project › Part 1 › Arduino › ndvi_log.csv.
  3. Send it to Claude (or say it's there), along with the photos, the time, the weather and the plant species.
What comes back: the NDVI chart for Slide 3, healthy and stressed averages, the repeatability figure, and a calibrated threshold.
For the slides, describe it honestly: a small sample of campus leaves in one session, not a controlled plant experiment.

If something goes wrong

ProblemFix
Red LED flashing fast at start-upSensor not found. Check the 4 sensor wires (A4 and A5 swapped?), then press the Uno's reset button.
No Arduino port foundCheck the USB cable, then pass the port name from Tools → Port (step 6).
Resource busy or the logger hangsThe Serial Monitor is still open. Close it, then press Ctrl + C in Terminal and start the logger again.
ModuleNotFoundError: serialpyserial isn't installed in this Terminal. Redo step 2 (or run source ~/ndvi-env/bin/activate).
"Sensor saturated" on screen, nothing savedToo bright. Move into light shade, or lower the gain (step 5).
"No white reference" or blank NDVIType w with the paper under the sensor.
Readings jump around a lotHold the sensor steadier on the spacer, keep your shadow off the leaf, and wait for steady light.
LED colour doesn't match the printed resultNote it down and carry on: the logged numbers are what matter.
